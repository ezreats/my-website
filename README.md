# EZR Eats

**Local food, big impact.** The website for EZR Eats, a Staples High School club redistributing unused restaurant food to Westport, CT community centers and shelters the same night it's prepared.

Founded by Eli Zev after a delivery to the Gillespie Center revealed how much good food goes unused while people in Westport face food insecurity. EZR Eats connects local restaurants with community centers, picking up, packaging, and delivering surplus food safely and free of charge.

## About this site

Single-file static site (`index.html`) — no build step, no dependencies. Open it directly in a browser or serve it from any static host (GitHub Pages, Cloudflare Pages, etc).

- **Our Story** — how and why EZR Eats started
- **How It Works** — the 3-step pickup-to-delivery process for restaurant partners
- **For Restaurants** — partnership benefits and a sign-up form
- **Get Involved** — ways to volunteer and a sign-up form
- **Impact** — honest, current numbers as the club grows
- **FAQ** — common questions from restaurants and neighbors
- **Contact** — phone, email, Instagram, and location

Forms submit via `mailto:` to elisamzev@gmail.com — no backend required.

## Deploying

This repo is meant to be served as-is. To point **ezreats.com** (registered on Cloudflare) at it:

1. In Cloudflare Pages, create a project connected to this repository.
2. Set the build output directory to the repo root (no build command needed).
3. Add `ezreats.com` as a custom domain once deployed.
